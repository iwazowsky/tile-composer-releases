Installers for Tile Composer, a desktop app for designing tiles and arranging patterns
that join.

Every version is kept under [Releases](https://github.com/iwazowsky/tile-composer-releases/releases).

## Opening it the first time

The installers are not yet signed with Apple's and Microsoft's paid certificates, so each
system asks once before opening them.

- **Mac:** open the app once and press Done on the message; then System Settings →
  Privacy & Security → Open Anyway.
- **Windows:** on "Windows protected your PC", press More info, then Run anyway.

Each release lists a SHA-256 fingerprint for its files, to check a download against.

This repository holds the installers only. The app is not open source.
